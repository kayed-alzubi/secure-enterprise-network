# secure-enterprise-network
A hypothetical company consists of a headquarters (HQ) and two branches, featuring several departments (Administration, Finance, IT, and Guest Services). It includes internal servers, a DMZ, and internet connectivity. Your task is to design, operate, secure, monitor, and automate this infrastructure.
